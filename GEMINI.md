# Antigravity / Gemini Workspace Rules

This repository uses a comprehensive shared agent and governance system.

Please refer directly to the root [AGENTS.md](AGENTS.md) and the persistent instruction system in [.agent/README.md](.agent/README.md).

All coding sessions must strictly respect:
1. Instruction discovery sequence defined in [AGENTS.md](AGENTS.md).
2. Global rules in [.agent/GLOBAL_RULES.md](.agent/GLOBAL_RULES.md).
3. Active role configured in `.agent/ACTIVE_ROLE.local` or `.agent/ACTIVE_ROLE`.
4. Phase gate discipline in [.agent/PHASES.md](.agent/PHASES.md) and [.agent/PROJECT_STATE.md](.agent/PROJECT_STATE.md).
5. Explicit procedural reviews in [.agent/AGENT_REGISTRY.md](.agent/AGENT_REGISTRY.md).
